Een reservekopie bewaart al uw notities in één `.zep`-bestand. Gebruik dat bestand om uw notities naar een andere Mac over te zetten.

:::caution
Het bestand is niet versleuteld. Iedereen die het kan openen, kan al uw notities lezen. Als u het in een gesynchroniseerde map bewaart, krijgt die dienst een kopie.
:::

## Een reservekopie maken

1. Druk op <kbd>⌘,</kbd> om de instellingen te openen.
2. Ga naar **Uw gegevens → Alles back-uppen**.
3. Klik op **Maak reservekopie…**.
4. Kies een locatie en klik op **Bewaar**.

Tijdens een opname kunt u geen reservekopie maken.

| In het bestand | Buiten het bestand |
| --- | --- |
| Alle notities, ook die in de prullenmand | Uw stemprofiel |
| Transcripten, samenvattingen en vergadergegevens | Agendaverbindingen |
| Mappen | Gedownloade modellen |
| Instellingen voor taal, vergaderstart en agenttoegang | Vergadergeluid |
| Geleerde woorden en geblokkeerde suggesties | |

## Een reservekopie terugzetten

Als u een reservekopie terugzet, vervangt u de notities, mappen en agenda-activiteiten op deze Mac. Dit kan niet terwijl Moxie een vergadering opneemt of verwerkt.

1. Ga naar **Instellingen → Uw gegevens → Herstellen uit reservekopie**.
2. Klik op **Reservekopie herstellen…**.
3. Selecteer het `.zep`-bestand.
4. Lees de melding **De notities op deze Mac vervangen?**.
5. Klik op **Herstellen en opnieuw starten**.

Moxie start opnieuw en toont de teruggezette notities. Deze Mac behoudt het stemprofiel en de instellingen voor de microfoon en het openen bij inloggen.

## Voorbeeld

De bestandsnaam bevat de datum en tijd:

```text
Moxie backup 2026-10-06 1530.zep
```
