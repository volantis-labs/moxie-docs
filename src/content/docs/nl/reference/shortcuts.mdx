Hier vindt u de toetscombinaties en tips. Elke groep heeft een link naar de volledige uitleg.

## Moxie-venster

| Toetsen | Resultaat |
| --- | --- |
| <kbd>⌘K</kbd> | Zoekvenster openen |
| <kbd>⌘F</kbd> | Zoekvenster openen als het invoegpunt buiten de notitie en het transcriptpaneel staat |
| <kbd>↓</kbd> <kbd>↑</kbd>, <kbd>Enter</kbd>, <kbd>Esc</kbd> | In het zoekvenster een resultaat selecteren, openen of het venster sluiten |
| <kbd>⌘\\</kbd> | Navigatiekolom verbergen of tonen |
| <kbd>⇧⌘\\</kbd> | Transcriptpaneel van een notitie tonen of verbergen |
| <kbd>⌘S</kbd> | Notitie direct bewaren |
| <kbd>⌘,</kbd> | **Instellingen** openen |
| <kbd>Enter</kbd> | In een chatveld de vraag versturen |

Meer informatie: [Zoeken](/moxie/docs/nl/find/search/), [Chat](/moxie/docs/nl/find/chat/), [Instellingen](/moxie/docs/nl/reference/settings/).

## Tekst opmaken

| Typ | Of druk op | Resultaat |
| --- | --- | --- |
| `**vet**` | <kbd>⌘B</kbd> | Vet |
| `*cursief*` | <kbd>⌘I</kbd> | Cursief |
| `~~doorgehaald~~` | <kbd>⇧⌘S</kbd> | Doorhalen |
| `` `code` `` | <kbd>⌘E</kbd> | Inlinecode |
| `# `, `## `, `### ` | <kbd>⌥⌘1</kbd>, <kbd>⌥⌘2</kbd>, <kbd>⌥⌘3</kbd> | Kop 1, 2, 3 |
| `> ` | <kbd>⇧⌘B</kbd> | Citaat |
| Drie backticks en dan een spatie | <kbd>⌥⌘C</kbd> | Codeblok |
| `---` | | Scheidingslijn |
| | <kbd>⌥⌘0</kbd> | Tekst |
| | <kbd>⌘Z</kbd>, <kbd>⇧⌘Z</kbd> | Ongedaan maken, opnieuw uitvoeren |

Selecteer tekst om het menu met **Vet**, **Cursief**, **Doorhalen**, **Inlinecode**, **Link bewerken**, **Omzetten naar** en **Zoek in transcript** te openen.

Meer informatie: [Opmaken terwijl u typt](/moxie/docs/nl/editor/formatting/).

## Slashmenu

| --- | --- |

## Opnemen

Als Moxie opneemt en het venster niet vooraan staat, verschijnt er een kleine zwevende bediening.

| Actie | Resultaat |
| --- | --- |
| Op **Stop** op de bediening klikken | Opname stoppen en bewaren. Moxie blijft op de achtergrond. |
| Op de bediening zelf klikken | Notitie openen |
| Bediening verslepen | Bediening verplaatsen. Moxie onthoudt de positie per beeldscherm. |
| **Start nu** of **Dit is geen vergadering** | Reageren op de melding van een gedetecteerde vergadering |
| **Blijf opnemen** | Automatisch stoppen aan het einde van een vergadering annuleren |
| **Meer** naast **Stop** in het transcriptpaneel | **Fysieke vergadering**, **Melding voor deelnemers kopiëren** |
| **Notitie openen** in de regel **De vergadering is in gang gezet.** | Notitie van de opname openen |
| In het veld **Stel een vraag over deze vergadering** typen | Tijdens de opname een vraag stellen |

De bediening blijft verborgen in gedeelde schermen en schermafbeeldingen.

Meer informatie: [De opnamebediening](/moxie/docs/nl/record/recording-control/), [Een opname starten en stoppen](/moxie/docs/nl/record/start-stop/).
