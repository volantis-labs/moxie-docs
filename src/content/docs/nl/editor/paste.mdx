Plak tekst in een notitie. Moxie zet Markdown om in opgemaakte tekst.

| U plakt | Resultaat |
| --- | --- |
| Markdown uit een bron met platte tekst, bijvoorbeeld een teksteditor | Opgemaakte tekst |
| Tekst van een webpagina | Tekst die opmaak zoals vet en lijsten behoudt |
| Een webadres | Een link |
| Een webadres op geselecteerde woorden | De woorden worden een link |
| Een Markdown-tabel of een tabel van een webpagina | Een tabel |
| Een schermafbeelding | Een afbeelding in **Mijn notities** |
| Tekst uit Word of Excel | Tekst, geen afbeelding van de tekst |

## De opmaak ongedaan maken

1. Plak Markdown-tekst.
2. Druk één keer op <kbd>⌘Z</kbd>. De notitie toont de Markdown-tekens als platte tekst.
3. Druk opnieuw op <kbd>⌘Z</kbd>. Moxie verwijdert de geplakte tekst.

## Plakken als platte tekst

Gebruik een van deze 2 manieren:

- Druk op <kbd>⇧⌘V</kbd>.
- Klik met de rechtermuisknop in de notitie → **Plak als platte tekst**.

Moxie plakt de tekens zoals ze zijn. In een codeblok blijft geplakte tekst altijd zoals deze is.

## Voorbeeld

Kopieer deze 2 regels uit een bestand met platte tekst en plak ze in een notitie:

```text
## Acties
- [ ] Stuur het **budget**
```

Moxie toont de kop "Acties" en één takenlijstonderdeel. "budget" is vet.
