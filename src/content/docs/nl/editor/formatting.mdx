Typ Markdown in een notitie. Moxie zet het om in opgemaakte tekst terwijl u typt.

## Blokken

Typ deze tekens aan het begin van een regel.

| Typ | Resultaat |
| --- | --- |
| `# ` | Kop |
| `- ` | Opsomming |
| `1. ` | Genummerde lijst |
| `[ ] ` | Takenlijst |
| `> ` | Citaat |
| Drie backticks en daarna een spatie | Codeblok |
| `---` | Scheidingslijn |

## Tekst

| Typ | Of druk op | Resultaat |
| --- | --- | --- |
| `**vet**` | <kbd>⌘B</kbd> | **vet** |
| `*cursief*` | <kbd>⌘I</kbd> | _cursief_ |
| `~~doorgehaald~~` | <kbd>⇧⌘S</kbd> | ~~doorgehaald~~ |
| `` `code` `` | <kbd>⌘E</kbd> | `code` |

## Voorbeeld

Typ deze regel:

```text
- Stuur het **budget** naar *Sam*
```

Moxie toont een opsommingsteken. "budget" is vet en "Sam" is cursief.
