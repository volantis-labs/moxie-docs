Install Moxie from a DMG file. Then download the models that make the transcript and the summaries on your Mac.

## Install the app

1. Read the [system requirements](/moxie/docs/get-started/requirements/).
2. Download the DMG file from [volantislabs.dev/moxie](https://volantislabs.dev/moxie/). There is one file for Apple silicon and one file for Intel.
3. Open the DMG file.
4. Move Moxie to the Applications folder.
5. Open Moxie from the Applications folder.

## Start Moxie for the first time

1. On the **Choose your language** screen, select a language.
2. Click **Continue**.
3. [Sign in](/moxie/docs/get-started/sign-in/).
4. Give the [permissions](/moxie/docs/get-started/permissions/).
5. On **Home**, find **Download models**. The line below it shows the size of the download.
6. Click **Download**.

You download the models only one time. You can use Moxie while the download continues. If the download stops, click **Resume** or **Retry**. The download continues from the same point.

## Example

When the download is complete, **Home** shows these lines:

```text
Models ready
Transcription and summaries now run on this Mac
```
