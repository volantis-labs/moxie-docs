title: Permissions

Give Moxie the macOS permissions. Moxie can then record your voice and the sound of the meeting.

| Permission | Moxie uses it to |
| --- | --- |
| **Microphone** | Record your voice. |
| **System audio** | Record the other persons in the meeting. |
| **Screen recording** | Find a meeting in a browser tab and start the recording for you. |
| **Accessibility** (optional) | Read the speaker names from the meeting app. |

## Give the permissions

Moxie shows the permission screen after you sign in.

1. Click **Allow** for one permission.
2. Answer the macOS message.
3. If macOS opens System Settings, turn on Moxie in **Screen & System Audio Recording**.
4. If macOS asks, select Quit & Reopen. Moxie shows the permission screen again.
5. Do steps 1 to 4 for each permission.
6. Click **Continue**.

To do this later, click **Set up later**. If a permission is missing, Moxie shows this screen again at the next start.

Without **Screen recording**, you can start a recording yourself.

## Example

The permission screen shows the status of each permission:

```text
Microphone         Your voice             Allowed
System audio       Everyone on the call   Allow
Screen recording   Browser meetings       Allow
```

## Change a permission later

Go to **Settings → Recording → Has macOS given Moxie access?** and click **Allow**. Moxie opens the applicable page of System Settings. **Accessibility** shows only in this list.
