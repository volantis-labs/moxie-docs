---
title: System requirements
description: The Mac and the macOS version that Moxie needs.
---

Moxie runs on a Mac that has the items in this table.

| Item | Requirement |
| --- | --- |
| macOS | Version 15 or later |
| Processor | Apple silicon, or Intel with 4 or more cores |
| Memory | 16 GB for all functions. With less than 16 GB, Moxie uses a lighter mode. |
| Account | A Google account or a Microsoft account |
| Network | For sign-in, model downloads, update checks and calendar access |

In the lighter mode, Moxie uses less memory. It writes the summary of a long meeting in smaller parts.

On an Intel Mac, the work after a meeting takes more time. The summary can take approximately 15 minutes for a 60-minute meeting.

If the macOS version or the processor is not sufficient, Moxie shows **This Mac can't run Moxie**. Click **Quit**.

## Do the hardware check again

1. Press <kbd>⌘,</kbd> to open **Settings**.
2. Click **Help & about**.
3. Below **Something not working?**, find **Check hardware again**.
4. Click **Check**.

## Example

The top of **Help & about** shows the version, the processor type and the result:

```text
Moxie 0.1.0 · Apple silicon · Meets requirements.
```
