Geben Sie Markdown in eine Notiz ein. Moxie formatiert den Text beim Schreiben.

## Blöcke

Geben Sie diese Zeichen am Zeilenanfang ein.

| Eingabe | Ergebnis |
| --- | --- |
| `# ` | Überschrift |
| `- ` | Aufzählung |
| `1. ` | Nummerierte Liste |
| `[ ] ` | Checkliste |
| `> ` | Zitat |
| Drei Backticks, dann ein Leerzeichen | Codeblock |
| `---` | Trennlinie |

## Fließtext

| Eingabe | Oder Tastenkürzel | Ergebnis |
| --- | --- | --- |
| `**fett**` | <kbd>⌘B</kbd> | **fett** |
| `*kursiv*` | <kbd>⌘I</kbd> | _kursiv_ |
| `~~durchgestrichen~~` | <kbd>⇧⌘S</kbd> | ~~durchgestrichen~~ |
| `` `code` `` | <kbd>⌘E</kbd> | `code` |

## Beispiel

Geben Sie diese Zeile ein:

```text
- Das **Budget** an *Sam* schicken
```

Moxie zeigt einen Aufzählungspunkt. „Budget“ ist fett und „Sam“ kursiv.
