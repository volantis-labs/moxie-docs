Ein Beleg ist ein kleiner Link hinter einem Satz in der Notiz. Er zeigt eine Zeit oder eine Zahl. Er öffnet das Transkript an der zugehörigen Zeile.

## Beleg öffnen

| Aktion | Ergebnis |
| --- | --- |
| Zeiger über einen Beleg bewegen | Eine Karte zeigt die Transkriptzeile. Mit **Im Transkript anzeigen** öffnen Sie das Transkript. |
| Auf einen Beleg klicken | Der Transkriptbereich öffnet sich an dieser Zeile |
| Beleg mit den Pfeiltasten auswählen und <kbd>Enter</kbd> drücken | Der Transkriptbereich öffnet sich an dieser Zeile |

## Beleg über die Transkriptsuche einfügen

1. Markieren Sie einen Satz in der Notiz. Neben der Auswahl erscheint ein Menü.
2. Klicken Sie auf **In Transkript suchen**. Sie sehen bis zu 3 Transkriptzeilen mit Sprecher und Zeitangabe.
3. Klicken Sie auf die passende Zeile.

Moxie fügt hinter der Auswahl einen Beleg ein. Der Transkriptbereich öffnet sich an dieser Zeile.

- Passt keine Zeile zum Satz, erscheint **Keine passende Zeile**.
- Die Taste **In Transkript suchen** erscheint nur bei Notizen mit Transkript.

## Beispiel

Markieren Sie „Sam schickt das Budget am Freitag“. Klicken Sie auf **In Transkript suchen**. Klicken Sie auf „Sam · 12:04“. Hinter dem Satz erscheint der Beleg „12:04“.
