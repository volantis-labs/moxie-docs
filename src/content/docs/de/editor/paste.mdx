Setzen Sie Text in eine Notiz ein. Moxie wandelt Markdown in formatierten Text um.

| Inhalt der Zwischenablage | Ergebnis |
| --- | --- |
| Markdown aus einer reinen Textquelle, etwa einem Texteditor | Formatierter Text |
| Text von einer Webseite | Text mit Formatierungen wie Fettschrift und Listen |
| Eine Webadresse | Ein Link |
| Eine Webadresse bei markiertem Text | Die Wörter werden zum Link |
| Markdown-Tabelle oder Tabelle von einer Webseite | Eine Tabelle |
| Ein Bildschirmfoto | Ein Bild in **Meine Notizen** |
| Text aus Word oder Excel | Bearbeitbarer Text statt eines Bildes |

## Formatierung widerrufen

1. Setzen Sie Markdown-Text ein.
2. Drücken Sie einmal <kbd>⌘Z</kbd>. Die Notiz zeigt die Markdown-Zeichen als reinen Text.
3. Drücken Sie erneut <kbd>⌘Z</kbd>. Moxie entfernt den eingesetzten Text.

## Als unformatierten Text einfügen

Wählen Sie einen der beiden Wege:

- Drücken Sie <kbd>⇧⌘V</kbd>.
- Rechtsklick in die Notiz → **Als unformatierten Text einfügen**.

Moxie setzt die Zeichen unverändert ein. In einem Codeblock bleibt eingesetzter Text immer unverändert.

## Beispiel

Kopieren Sie diese zwei Zeilen aus einer reinen Textdatei und setzen Sie sie in eine Notiz ein:

```text
## Aufgaben
- [ ] Das **Budget** schicken
```

Moxie zeigt die Überschrift „Aufgaben“ und einen Checklistenpunkt. „Budget“ ist fett.
