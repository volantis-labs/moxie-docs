Geben Sie `@` in einer Notiz ein, um eine Person zu erwähnen. Die Erwähnung verlinkt auf ihre Seite.

1. Geben Sie `@` am Zeilenanfang oder nach einem Leerzeichen ein. Eine Personenliste öffnet sich. Die Personen aus dieser Notiz stehen oben.
2. Geben Sie die ersten Buchstaben eines Namens oder einer E-Mail-Adresse ein, um weitere Personen zu finden.
3. Wählen Sie mit <kbd>↓</kbd> oder <kbd>↑</kbd> eine Person aus.
4. Drücken Sie <kbd>Enter</kbd>.

Die Liste zeigt nur Namen. Bei gleichen Namen zeigt sie auch die E-Mail-Adressen.

Im Schrägstrichmenü öffnet **Person erwähnen** dieselbe Liste.

## Neue Person hinzufügen

1. Geben Sie `@` und dann den Namen der neuen Person ein.
2. Wählen Sie **Person „Kim Lee“ hinzufügen**. Die Zeile zeigt den eingegebenen Namen.
3. Drücken Sie <kbd>Enter</kbd>.

## Seite einer Person öffnen

1. Klicken Sie auf eine Erwähnung. Die Seite der Person öffnet sich mit **Erwähnungen** und **Besprechungen**.
2. Klicken Sie auf eine Zeile unter **Erwähnungen**. Die Notiz öffnet sich an dieser Zeile.

## Beispiel

Geben Sie diesen Text ein:

```text
@pri
```

Die Liste zeigt Personen, deren Name mit „pri“ beginnt, etwa „Priya Shah“. Drücken Sie <kbd>Enter</kbd>. In der Notiz steht die Erwähnung „@Priya Shah“.
