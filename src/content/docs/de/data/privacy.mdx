Moxie erstellt das Transkript, die Sprechernamen und die Zusammenfassungen auf Ihrem Mac. Moxie versendet keine Meetinginhalte.

## Was auf Ihrem Mac bleibt

| Daten | Verarbeitung durch Moxie |
| --- | --- |
| Audio | Moxie behält die Aufnahme, bis die Notiz verarbeitet ist. Dann löscht Moxie die Aufnahme. Schlägt ein Schritt fehl, behält Moxie sie für einen neuen Versuch. |
| Transkripte, Notizen, Zusammenfassungen, Sprechernamen und Bildschirmtext | Moxie speichert sie auf Ihrem Mac. |
| Kalenderereignisse | Moxie liest Ihren Kalender ohne Schreibzugriff und speichert die Ereignisse auf Ihrem Mac. |

## Notizen auf dem Datenträger schützen

Moxie verschlüsselt seine Dateien nicht. FileVault ist eine Funktion von macOS und verschlüsselt das Laufwerk Ihres Mac.

Ist FileVault deaktiviert, erscheint unter **Einstellungen → Ihre Daten** die Meldung **FileVault ist deaktiviert**. Klicken Sie auf **Überprüfen Sie FileVault**, um die FileVault-Einstellungen von macOS zu öffnen.

## Wann Moxie das Netzwerk nutzt

| Verwendung | Zeitpunkt |
| --- | --- |
| Modell-Downloads | Bei der Einrichtung und beim erneuten Laden eines Modells |
| Suche nach Updates | Solange Moxie geöffnet ist |
| Kalender | Solange ein Google- oder Microsoft-Konto verbunden ist |
| Diagnosedaten | Wenn Diagnosedaten aktiviert sind. Siehe [Diagnosedaten](/moxie/docs/de/data/diagnostics/). |
| Formular für die geschäftliche E-Mail-Adresse | Nur wenn Sie das Formular unter **Geschäftliche E-Mail teilen…** absenden |

Wenn Sie eine Notiz löschen, bleiben Ihre exportierten Dateien, Sicherungen und Time-Machine-Kopien erhalten.

## Beispiel

Den vollständigen Hinweis finden Sie in der App unter **Einstellungen → Ihre Daten → Datenschutzhinweis**.

Lesen Sie die vollständige [Datenschutzerklärung](https://volantislabs.dev/moxie/privacy/).
