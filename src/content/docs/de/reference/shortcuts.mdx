Hier finden Sie die Tastenkürzel und Tipps. Jeder Abschnitt verweist auf die ausführliche Anleitung.

## Moxie-Fenster

| Taste | Ergebnis |
| --- | --- |
| <kbd>⌘K</kbd> | Suche öffnen |
| <kbd>⌘F</kbd> | Suche öffnen, wenn die Einfügemarke außerhalb der Notiz und des Transkriptbereichs steht |
| <kbd>↓</kbd> <kbd>↑</kbd>, <kbd>Enter</kbd>, <kbd>Esc</kbd> | In der Suche ein Ergebnis wählen, öffnen oder die Suche schließen |
| <kbd>⌘\\</kbd> | Seitenleiste aus- oder einblenden |
| <kbd>⇧⌘\\</kbd> | Transkriptbereich einer Notiz ein- oder ausblenden |
| <kbd>⌘S</kbd> | Notiz sofort sichern |
| <kbd>⌘,</kbd> | **Einstellungen** öffnen |
| <kbd>Enter</kbd> | Im Chatfeld die Frage senden |

Anleitungen: [Suche](/moxie/docs/de/find/search/), [Chat](/moxie/docs/de/find/chat/), [Einstellungen](/moxie/docs/de/reference/settings/).

## Text formatieren

| Eingabe | Oder Tastenkürzel | Ergebnis |
| --- | --- | --- |
| `**fett**` | <kbd>⌘B</kbd> | Fett |
| `*kursiv*` | <kbd>⌘I</kbd> | Kursiv |
| `~~durchgestrichen~~` | <kbd>⇧⌘S</kbd> | Durchgestrichen |
| `` `code` `` | <kbd>⌘E</kbd> | Inline-Code |
| `# `, `## `, `### ` | <kbd>⌥⌘1</kbd>, <kbd>⌥⌘2</kbd>, <kbd>⌥⌘3</kbd> | Überschrift 1, 2, 3 |
| `> ` | <kbd>⇧⌘B</kbd> | Zitat |
| Drei Backticks, dann ein Leerzeichen | <kbd>⌥⌘C</kbd> | Codeblock |
| `---` | | Trennlinie |
| | <kbd>⌥⌘0</kbd> | Fließtext |
| | <kbd>⌘Z</kbd>, <kbd>⇧⌘Z</kbd> | Rückgängig machen, wiederholen |

Markieren Sie Text. Das Menü enthält **Fett**, **Kursiv**, **Durchgestrichen**, **Inline-Code**, **Link bearbeiten**, **Umwandeln in** und **In Transkript suchen**.

Anleitung: [Beim Schreiben formatieren](/moxie/docs/de/editor/formatting/).

## Schrägstrichmenü

| Eingabe oder Taste | Ergebnis |
| --- | --- |
| `/` am Zeilenanfang oder nach einem Leerzeichen | Menü öffnen |
| Buchstaben | Liste filtern |
| <kbd>↓</kbd> <kbd>↑</kbd> | Eintrag auswählen |
| <kbd>Enter</kbd> oder <kbd>Tab</kbd> | Eintrag einfügen |
| <kbd>Esc</kbd> | Menü schließen. Der eingegebene Text bleibt erhalten. |

Anleitung: [Schrägstrichmenü](/moxie/docs/de/editor/slash-menu/).

| --- | --- |
| `- ` oder <kbd>⇧⌘8</kbd> | Aufzählung |
| `1. ` oder <kbd>⇧⌘7</kbd> | Nummerierte Liste |

## Links und Erwähnungen

| Eingabe oder Taste | Ergebnis |
| --- | --- |
| Wörter markieren, dann <kbd>⌘K</kbd> | Wörter mit einer Webadresse oder Notiz verknüpfen |
| <kbd>⌘K</kbd> mit der Einfügemarke im Link | **Link öffnen**, **Link entfernen** |
| Wörter markieren, dann eine Webadresse einsetzen | Die Wörter werden zum Link |
| Auf einen Link klicken | Webadresse oder Notiz öffnen |
| `@` | Person erwähnen |
| Auf eine Erwähnung klicken | Seite der Person öffnen |

Anleitungen: [Links](/moxie/docs/de/editor/links/), [Personen erwähnen](/moxie/docs/de/editor/mentions/).

## Suchen und ersetzen

| Taste | Ergebnis |
| --- | --- |
| <kbd>⌘F</kbd> in einer Notiz | Suchleiste mit den markierten Wörtern öffnen |
| <kbd>Enter</kbd> oder <kbd>⌘G</kbd> | Nächster Treffer |
| <kbd>⇧Enter</kbd> oder <kbd>⇧⌘G</kbd> | Vorheriger Treffer |
| <kbd>Esc</kbd> | Suchleiste schließen |
| <kbd>⌘F</kbd> im Transkriptbereich | Zum Feld **Transkript durchsuchen** wechseln |
| <kbd>Enter</kbd>, <kbd>⇧Enter</kbd> im Feld **Transkript durchsuchen** | Nächster bzw. vorheriger Treffer |

Anleitung: [Suchen und ersetzen](/moxie/docs/de/editor/find-replace/).

## Tabellen und Bilder

| Eingabe oder Taste | Ergebnis |
| --- | --- |
| `\| Artikel \| Preis \|`, dann <kbd>Enter</kbd> | Tabelle erstellen |
| <kbd>Tab</kbd>, <kbd>⇧Tab</kbd> | Nächste bzw. vorherige Zelle. In der letzten Zelle fügt <kbd>Tab</kbd> eine Zeile hinzu. |

| Bildschirmfoto einsetzen oder Bilddatei in die Notiz ziehen | Bild einfügen |
| Auf ein Bild klicken | Beschreibung bearbeiten |

Anleitungen: [Tabellen](/moxie/docs/de/editor/tables/), [Bilder](/moxie/docs/de/editor/images/).

## Aufnahme

Wenn Moxie aufnimmt und das Fenster im Hintergrund ist, erscheint eine kleine schwebende Steuerung auf dem Bildschirm.

| Aktion | Ergebnis |
| --- | --- |
| Auf der Steuerung auf **Stopp** klicken | Aufnahme stoppen und sichern. Moxie bleibt im Hintergrund. |
| Auf die Fläche der Steuerung klicken | Notiz öffnen |
| Steuerung ziehen | Steuerung verschieben. Moxie merkt sich die Position für jeden Bildschirm. |
| **Jetzt aufnehmen** oder **Dieses Meeting nicht** | Auf die Meldung zu einem erkannten Meeting reagieren |
| **Aufnahme fortsetzen** | Automatischen Stopp am Meetingende abbrechen |
| **Mehr** neben **Stopp** im Transkriptbereich | **Besprechung vor Ort**, **Teilnahmehinweis kopieren** |
| **Notiz öffnen** in der Zeile **Gemeinschaftsmeeting im Gange.** | Notiz zur Aufnahme öffnen |
| In das Feld **Frage zu diesem Meeting stellen** schreiben | Während der Aufnahme eine Frage stellen |

Die Steuerung ist in Bildschirmfreigaben und Bildschirmfotos unsichtbar.

Anleitungen: [Die Aufnahmesteuerung](/moxie/docs/de/record/recording-control/), [Aufnahme starten und stoppen](/moxie/docs/de/record/start-stop/).
