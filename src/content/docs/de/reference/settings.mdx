Drücken Sie <kbd>⌘,</kbd>, um die Einstellungen zu öffnen. Für jeden der fünf Bereiche finden Sie hier eine Tabelle.

## Allgemein

| Einstellung | Funktion | Standardwert |
| --- | --- | --- |
| **Welche Sprache soll Moxie verwenden?** | Legt die Sprache der App, der Zusammenfassungen und des Chats fest. Das Transkript bleibt in der gesprochenen Sprache. | Englisch |
| **Soll Moxie Ihre Stimme erkennen?** | Nimmt drei Stimmproben auf. Danach kennzeichnet Moxie Ihre Beiträge mit „Ich“. | Kein Stimmprofil |
| **Kalenderkonto** | Zeigt Ihr Google- oder Microsoft-365-Konto. Moxie liest Ihren Kalender ohne Schreibzugriff. Mit **Kalenderauswahl anzeigen** wählen Sie Kalender aus. Mit **Abmelden** trennen Sie das Konto. | Ihr Anmeldekonto |
| **Moxie beim Anmelden öffnen?** | Startet Moxie bei der Anmeldung auf Ihrem Mac. | Aus |
| **Wie lange bleiben gelöschte Notizen im Papierkorb?** | Zeigt die Aufbewahrungsdauer. Moxie löscht Notizen im Papierkorb nach 30 Tagen. Sie können diesen Wert nicht ändern. | 30 Tage |

## Aufnahme

| Einstellung | Funktion | Standardwert |
| --- | --- | --- |
| **Hat macOS Moxie Zugriff gewährt?** | Zeigt die Berechtigungen **Mikrofon**, **Systemaudio**, **Bildübertragung** und **Zugänglichkeit**. Mit **Erlauben** öffnen Sie die zugehörige macOS-Einstellung. | Erst nach Ihrer Freigabe erlaubt |
| **Was soll Moxie tun, wenn ein Meeting beginnt?** | **Mich fragen**, **10 s herunterzählen** oder **5 s herunterzählen**. | **10 s herunterzählen** |
| **Welches Mikrofon soll Moxie verwenden?** | Mit **System folgen** verwendet Moxie das Standardmikrofon von macOS. Sie können auch ein bestimmtes Mikrofon wählen. | **System folgen** |
| **Nutzen Sie Google Meet?** | Zeigt, ob die Browsererweiterung verbunden ist. Mit **Für Chrome oder Edge installieren** öffnen Sie die Seite der Erweiterung. | Nicht installiert |

## KI-Funktionen

| Einstellung | Funktion | Standardwert |
| --- | --- | --- |
| **Sollen verbesserte Notizen Ihre eigenen Notizen verwenden?** | Gibt dem Modell beim Erstellen der verbesserten Notizen auch Ihre eigenen Notizen. | Aus |
| **Dürfen KI-Agenten auf diesem Mac Ihre Notizen lesen?** | Aktiviert den Agentenzugriff. Siehe [Agentenzugriff aktivieren](/moxie/docs/de/agents/access/). | Aus |
| **Zu einer KI-App hinzufügen** | **Konfiguration MCP kopieren** kopiert die Konfiguration für einen MCP-Client. | Keine |
| **Im Terminal verwenden** | **Installationsbefehl** installiert den Befehl `moxie`. Mit **Befehl entfernen** entfernen Sie ihn. | Nicht installiert |
| **Anleitung für Agenten (SKILL.md)** | **Anzeigen** zeigt die Anweisungen an. Mit **Kopieren** kopieren Sie sie. | Keine |
| **Technische Details anzeigen** | Zeigt Hardware, Modelle und Modell-Downloads. | Geschlossen |

## Ihre Daten

| Einstellung | Funktion | Standardwert |
| --- | --- | --- |
| **Alles sichern** | **Backup erstellen…** sichert alle Notizen in einer `.zep`-Datei. | Keine |
| **Aus Backup wiederherstellen** | **Backup wiederherstellen…** ersetzt die Notizen auf diesem Mac durch die Notizen aus der Sicherung. | Keine |
| **Notizen exportieren oder importieren** | **Exportieren…** speichert jede Notiz als JSON und Markdown. **Importieren…** liest exportierte Notizen ein. | Keine |
| **Gelernte Wörter** | Zeigt bestätigte Wörter. Mit **Entfernen** löschen Sie ein Wort. Moxie entfernt Wörter, die Sie 90 Tage lang nicht verwenden. | Leer |
| **Diagnosedaten senden, um Probleme zu beheben?** | Sendet Absturzberichte und Nutzungszahlen ohne Meetinginhalte. | Ein. In Regionen mit vorheriger Zustimmung bis zu Ihrer Zustimmung aus. |
| **Datenschutzhinweis** | Zeigt den Datenschutzhinweis. | Geschlossen |
| **Was gesendet wurde** | Zeigt jede Diagnosemeldung. Mit **Zurücksetzen** erhalten Sie eine neue Kennung (**Installations-ID**). | Geschlossen |
| **Moxie bei der Arbeit verwenden?** | **Geschäftliche E-Mail teilen…** öffnet ein Formular. Wenn Sie es absenden, kann Moxie Sie über Ihre geschäftliche E-Mail-Adresse zu Teamfunktionen kontaktieren. | Nicht gesendet |

Ist FileVault deaktiviert, sehen Sie hier auch **FileVault ist deaktiviert** und die Taste **Überprüfen Sie FileVault**.

## Hilfe und Info

| Einstellung | Funktion | Standardwert |
| --- | --- | --- |
| **Problem melden** | **Melden…** öffnet eine GitHub-Meldung mit Gerätedaten und Fehlercodes ohne Meetinginhalte. | Keine |
| **Berichten Sie eine Sicherheitsproblematik** | **Melden…** öffnet die GitHub-Seite für vertrauliche Meldungen zu Sicherheitslücken. | Keine |
| **Hardware erneut prüfen** | **Prüfen** prüft die Hardware erneut. Das Ergebnis zeigt, ob Ihr Mac Moxie ausführen kann. | Keine |
| **Lizenzen** | **Ansehen** zeigt die Lizenzen der Drittanbieter. Moxie ist quelloffen und steht unter der GPL 3.0. | Geschlossen |
| **Details zum Support-Paket anzeigen** | **Unterstützungsbundle überprüfen** zeigt die lokalen Protokolle, bevor Sie sie als ZIP-Datei sichern. Moxie lädt nichts hoch. | Geschlossen |

## Beispiel

Gehen Sie zu **Einstellungen → Aufnahme → Was soll Moxie tun, wenn ein Meeting beginnt?** und wählen Sie **5 s herunterzählen**, um den Countdown zu ändern.
