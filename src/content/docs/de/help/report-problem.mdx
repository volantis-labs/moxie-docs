Melden Sie ein Problem direkt aus Moxie. Moxie ergänzt die technischen Daten. Sie beschreiben, was passiert ist.

1. Drücken Sie <kbd>⌘,</kbd>, um **Einstellungen** zu öffnen.
2. Klicken Sie auf **Hilfe und Info**.
3. Suchen Sie unter **Funktioniert etwas nicht?** nach **Problem melden**.
4. Klicken Sie auf **Melden…**. Ihr Browser öffnet eine neue Problemmeldung auf GitHub.
5. Beschreiben Sie, was passiert ist.
6. Lesen Sie den gesamten Text. Senden Sie dann die Meldung ab.

Moxie ergänzt die App-Version, Angaben zu Ihrem Mac und die letzten Fehlercodes. Meetinginhalte sind nicht enthalten.

Die Meldung ist öffentlich. Sie benötigen ein GitHub-Konto. Fügen Sie keine Transkripte, Notiztitel, Namen, Ordnernamen oder Dateipfade ein.

Wenn Sie keine öffentliche Meldung wünschen, schreiben Sie eine E-Mail an [hello@getmoxieapp.com](mailto:hello@getmoxieapp.com).

## Supportpaket erstellen

Ein Supportpaket ist eine ZIP-Datei mit den lokalen Protokollen und einem Profil Ihres Mac. Moxie lädt sie nicht hoch.

1. Klicken Sie unter **Hilfe und Info** auf **Details zum Support-Paket anzeigen**.
2. Klicken Sie auf **Unterstützungsbundle überprüfen**.
3. Lesen Sie den Inhalt.
4. Klicken Sie auf **ZIP-Datei speichern**.
5. Hängen Sie die Datei an Ihre Meldung an.

## Beispiel

Die Meldung beginnt zum Beispiel so:

```text
Moxie 0.1.0 auf macOS 15.1.0, M2 (arm64), 8 Kerne, 16 GiB RAM.
Zuverlässigkeitscodes: Keine Notizen aufgenommen..
```
