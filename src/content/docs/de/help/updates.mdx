Moxie findet und lädt neue Versionen automatisch. Sie starten die Installation mit einem Klick.

1. Lassen Sie Moxie geöffnet. Moxie sucht bei jedem Start, einmal pro Stunde und nach jeder Aufnahme nach einer neuen Version.
2. Warten Sie, bis Moxie die neue Version geladen hat. Während des Downloads erscheint keine Meldung.
3. Achten Sie oben im Moxie-Fenster auf die Meldung **Moxie ist bereit für ein Update**.
4. Klicken Sie auf **Für das Update neu starten**. Moxie startet neu und installiert die neue Version.

Während einer Aufnahme lädt oder installiert Moxie keine Updates. Beginnt eine Aufnahme, hält Moxie den Download an. Nach der Aufnahme läuft er weiter. Die Meldung erscheint nur außerhalb einer Aufnahme.

Moxie installiert das Update erst, wenn Sie auf **Für das Update neu starten** klicken. Die Updates stammen aus den Moxie-Veröffentlichungen auf GitHub.

## Beispiel

So sieht die Meldung aus:

```text
Moxie ist bereit für ein Update
Starten Sie Moxie zwischen Meetings neu, um das Update zu installieren.    Für das Update neu starten
```

Ihre Version finden Sie unter **Einstellungen → Hilfe und Info**. Sie steht oben auf der Seite:

```text
Moxie 0.1.0 · Apple silicon · Erfüllt die Anforderungen.
```
