Suchen Sie die Meldung von Moxie und führen Sie die zugehörige Aktion aus.

## Während einer Aufnahme

Diese Meldungen erscheinen in der Aufnahmesteuerung.

| Meldung | Abhilfe |
| --- | --- |
| **Ihr Mikrofon ist stumm** | Wenn Sie das Mikrofon in der Meeting-App stummgeschaltet haben, müssen Sie nichts tun. Klicken Sie andernfalls auf **Microphone auswählen**. |
| **Kein Besprechungston** | Klicken Sie auf **Ausgabe prüfen**. Prüfen Sie, ob der Ton des Meetings über den gewählten Ausgang läuft. |
| **Gerät gewechselt zu** und ein Gerätename | Klicken Sie auf **OK**. Die Aufnahme läuft weiter. |
| **Laufwerk fast voll** | Klicken Sie auf **Raum freimachen**. Löschen Sie nicht benötigte Dateien. |
| **Mikrofonzugriff entzogen** | Klicken Sie auf **Einstellungen öffnen**. Aktivieren Sie Moxie. |
| **System-Audio-Permission wurde deaktiviert** | Klicken Sie auf **Systemeinstellungen öffnen**. Aktivieren Sie Moxie. |

## Vor oder nach einer Aufnahme

| Meldung | Abhilfe |
| --- | --- |
| **Download unterbrochen** | Klicken Sie auf **Wiederholen**. Prüfen Sie die Netzwerkverbindung und den freien Speicherplatz auf Ihrem Mac. |
| **Moxie benötigt Kalenderzugriff** | Melden Sie sich erneut an. Erlauben Sie den Zugriff auf Ihre Kalender. |
| **Fragen Sie Ihre IT-Administration** | Bitten Sie Ihre IT-Administration, Moxie zuzulassen. Melden Sie sich dann erneut an. |
| **Anmeldung abgelaufen.** | Gehen Sie zu **Einstellungen → Allgemein → Kalenderkonto**. Klicken Sie auf **Wiederherstellen**. |

Fehlt eine Berechtigung, gehen Sie zu **Einstellungen → Aufnahme** und klicken Sie auf **Erlauben**.

## Beispiel

Sie schließen während eines Meetings Kopfhörer an. Die Aufnahmesteuerung zeigt diese Zeile:

```text
Gerät gewechselt zu AirPods Pro    OK
```
