Erteilen Sie Moxie die macOS-Berechtigungen. Moxie kann dann Ihre Stimme und den Ton des Meetings aufnehmen.

| Berechtigung | Damit kann Moxie |
| --- | --- |
| **Mikrofon** | Ihre Stimme aufnehmen. |
| **Systemaudio** | Die anderen Personen im Meeting aufnehmen. |
| **Bildschirmaufnahme** | Ein Meeting in einem Browsertab finden und die Aufnahme für Sie starten. |
| **Zugänglichkeit** (optional) | Die Sprechernamen aus der Meeting-App lesen. |

## Berechtigungen erteilen

Moxie zeigt das Berechtigungsfenster, nachdem Sie sich angemeldet haben.

1. Klicken Sie bei einer Berechtigung auf **Erlauben**.
2. Beantworten Sie die Meldung von macOS.
3. Wenn macOS die Systemeinstellungen öffnet, aktivieren Sie Moxie im angezeigten Bereich, zum Beispiel unter **Aufnahme von Bildschirm & Systemaudio**.
4. Wenn macOS fragt, wählen Sie „Beenden & erneut öffnen“. Moxie zeigt das Berechtigungsfenster erneut.
5. Wiederholen Sie die Schritte 1 bis 4 für jede Berechtigung.
6. Klicken Sie auf **Fortfahren**.

Um dies später zu tun, klicken Sie auf **Später einrichten**. Wenn eine Berechtigung fehlt, zeigt Moxie dieses Fenster beim nächsten Start erneut.

Ohne **Bildschirmaufnahme** können Sie eine Aufnahme selbst starten.

## Beispiel

Das Berechtigungsfenster zeigt den Status jeder Berechtigung:

```text
Mikrofon            Ihre Stimme       Erlaubt
Systemaudio         Alle im Gespräch  Erlauben
Bildschirmaufnahme  Browser-Meetings  Erlauben
```

## Berechtigung später ändern

Gehen Sie zu **Einstellungen → Aufnahme → Hat macOS Moxie Zugriff gewährt?** und klicken Sie auf **Erlauben**. Moxie öffnet die passende Seite der Systemeinstellungen. **Zugänglichkeit** erscheint nur in dieser Liste.
