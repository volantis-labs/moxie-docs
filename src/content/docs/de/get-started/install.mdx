Installieren Sie Moxie aus einer DMG-Datei. Laden Sie dann die Modelle, die das Transkript und die Zusammenfassungen auf Ihrem Mac erstellen.

## App installieren

1. Lesen Sie die [Systemanforderungen](/moxie/docs/de/get-started/requirements/).
2. Laden Sie die DMG-Datei von [volantislabs.dev/moxie](https://volantislabs.dev/moxie/). Es gibt eine Datei für Macs mit Apple Chip und eine Datei für Intel-Macs.
3. Öffnen Sie die DMG-Datei.
4. Bewegen Sie Moxie in den Ordner „Programme“.
5. Öffnen Sie Moxie im Ordner „Programme“.

## Moxie zum ersten Mal starten

1. Wählen Sie im Fenster **Sprache wählen** eine Sprache.
2. Klicken Sie auf **Fortfahren**.
3. [Anmelden und Kalender verbinden](/moxie/docs/de/get-started/sign-in/).
4. Erteilen Sie die [Berechtigungen](/moxie/docs/de/get-started/permissions/).
5. Suchen Sie auf der **Startseite** den Eintrag **Modelle laden**. Die Zeile darunter zeigt die Größe des Downloads.
6. Klicken Sie auf **Laden**.

Sie laden die Modelle nur einmal. Sie können Moxie verwenden, während der Download läuft. Wenn der Download stoppt, klicken Sie auf **Fortsetzen** oder **Wiederholen**. Der Download geht an derselben Stelle weiter.

## Beispiel

Wenn der Download abgeschlossen ist, zeigt die **Startseite** diese Zeilen:

```text
Modelle bereit
Transkription und Zusammenfassungen laufen jetzt auf diesem Mac
```
