Add a PNG or JPEG image to **My notes**. Moxie keeps the image with the note on your Mac.

| Action | Result |
| --- | --- |
| Copy a screenshot, then press <kbd>⌘V</kbd> in the note | The image shows at the caret |
| Drag an image file into the note | The image shows where you drop it |
| Type `/image`, then press <kbd>Enter</kbd> | A file window opens. Select one or more files. |

- The maximum size of a file is 20 MB.
- Moxie makes a large image smaller. The long side becomes a maximum of 1600 pixels.
- If Moxie cannot use a file, it shows "This image is too large or could not be read."

## Add a description

1. Click the image. A text field shows below the image.
2. Type the description.

## Find text in an image

Moxie reads the text in each image. Search finds the note by words that are only in one of its images.

## Example

1. Press <kbd>⌃⇧⌘4</kbd> and select an area of the screen. macOS copies the screenshot.
2. Click in **My notes**.
3. Press <kbd>⌘V</kbd>.
