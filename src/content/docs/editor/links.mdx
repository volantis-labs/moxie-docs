Link words in a note to a web address or to a different note.

1. Select the words.
2. Press <kbd>⌘K</kbd>. The **URL or note title** field opens.
3. Type or paste a web address. Or type the first letters of a word in the title of a note.
4. If the list shows more than one note, press <kbd>↓</kbd> or <kbd>↑</kbd> to select the correct note.
5. Press <kbd>Enter</kbd>.

The words become a link. The text of the words does not change.

## More ways

| Action | Result |
| --- | --- |
| Type a web address, then a space | The address becomes a link |
| Paste a web address | The address becomes a link |
| Select words, then paste a web address | The words become a link |
| Click a link | A web address opens in your browser. A note link opens that note. |
| <kbd>⌘K</kbd> with the caret in a link | A menu with **Open link** and **Remove link** |
| Right-click a link | A menu with **Copy link**. For a web address, the menu also has **Open link**. |

If no text is selected and the caret is not in a link, <kbd>⌘K</kbd> opens search.

## Example

Select "pricing notes". Press <kbd>⌘K</kbd>. Type this text:

```text
example.com/pricing
```

The list shows **Link to https://example.com/pricing**. Press <kbd>Enter</kbd>.
