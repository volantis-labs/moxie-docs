Type Markdown in a note. Moxie changes it to formatted text while you type.

## Blocks

Type these characters at the start of a line.

| Type | Result |
| --- | --- |
| `# ` | Heading |
| `- ` | Bullet list |
| `1. ` | Numbered list |
| `[ ] ` | Checklist |
| `> ` | Quote |
| Three backticks, then a space | Code block |
| `---` | Divider |

## Text

| Type | Or press | Result |
| --- | --- | --- |
| `**bold**` | <kbd>⌘B</kbd> | **bold** |
| `*italic*` | <kbd>⌘I</kbd> | _italic_ |
| `~~strike~~` | <kbd>⇧⌘S</kbd> | ~~strike~~ |
| `` `code` `` | <kbd>⌘E</kbd> | `code` |

## Example

Type this line:

```text
- Send the **budget** to *Sam*
```

Moxie shows a bullet. "budget" is bold and "Sam" is italic.
