title: Paste

Paste text into a note. Moxie changes Markdown to formatted text.

| You paste | Result |
| --- | --- |
| Markdown from a plain-text source, for example a text editor | Formatted text |
| Text from a web page | Text that keeps formats such as bold and lists |
| A web address | A link |
| A web address on selected words | The words become a link |
| A Markdown table or a table from a web page | A table |
| A screenshot | An image in **My notes** |
| Text from Word or Excel | Text, not a picture of the text |

## Undo the format

1. Paste Markdown text.
2. Press <kbd>⌘Z</kbd> one time. The note shows the Markdown characters as plain text.
3. Press <kbd>⌘Z</kbd> again. Moxie removes the pasted text.

## Paste as plain text

Use one of these 2 ways:

- Press <kbd>⇧⌘V</kbd>.
- Right-click in the note → **Paste as plain text**.

Moxie pastes the characters as they are. In a code block, pasted text always stays as it is.

## Example

Copy these 2 lines from a plain-text file and paste them into a note:

```text
## Actions
- [ ] Send the **budget**
```

Moxie shows the heading "Actions" and one checklist item. "budget" is bold.
