Type `@` in a note to mention a person. A mention is a link to the page of that person.

1. Type `@` at the start of a line or after a space. A list of people opens. The people of this note are first.
2. Type the first letters of a name or of an email address to find other people.
3. Press <kbd>↓</kbd> or <kbd>↑</kbd> to select a person.
4. Press <kbd>Enter</kbd>.

The list shows names only. If two people in the list have the same name, the list also shows their email addresses.

In the slash menu, **Mention a person** opens the same list.

## Add a new person

1. Type `@`, then the name of the new person.
2. Select **Add person “Kim Lee”**. The row shows the name that you typed.
3. Press <kbd>Enter</kbd>.

## Open the page of a person

1. Click a mention. The page of the person opens with **Mentions** and **Meetings**.
2. Click a row below **Mentions**. The note opens at that line.

## Example

Type this text:

```text
@pri
```

The list shows the people whose name starts with "pri", for example "Priya Shah". Press <kbd>Enter</kbd>. The note shows the mention "@Priya Shah".
