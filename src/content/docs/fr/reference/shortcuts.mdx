Cette page regroupe les raccourcis et astuces. Chaque section contient un lien vers le guide détaillé.

## Fenêtre de Moxie

| Touches | Résultat |
| --- | --- |
| <kbd>⌘K</kbd> | Ouvrir la recherche |
| <kbd>⌘F</kbd> | Ouvrir la recherche si le curseur est en dehors de la note et du volet de transcription |
| <kbd>↓</kbd> <kbd>↑</kbd>, <kbd>Enter</kbd>, <kbd>Esc</kbd> | Dans la recherche : sélectionner un résultat, l’ouvrir ou fermer la recherche |
| <kbd>⌘\\</kbd> | Masquer ou afficher la barre latérale |
| <kbd>⇧⌘\\</kbd> | Afficher ou masquer le volet de transcription d’une note |
| <kbd>⌘S</kbd> | Enregistrer la note immédiatement |
| <kbd>⌘,</kbd> | Ouvrir **Réglages** |
| <kbd>Enter</kbd> | Dans le champ de chat : envoyer la question |

Guides : [Recherche](/moxie/docs/fr/find/search/), [Chat](/moxie/docs/fr/find/chat/), [Réglages](/moxie/docs/fr/reference/settings/).

## Mettre en forme le texte

| Saisie | Ou raccourci | Résultat |
| --- | --- | --- |
| `**gras**` | <kbd>⌘B</kbd> | Gras |
| `*italique*` | <kbd>⌘I</kbd> | Italique |
| `~~barré~~` | <kbd>⇧⌘S</kbd> | Barré |
| `` `code` `` | <kbd>⌘E</kbd> | Code en ligne |
| `# `, `## `, `### ` | <kbd>⌥⌘1</kbd>, <kbd>⌥⌘2</kbd>, <kbd>⌥⌘3</kbd> | Titre de niveau 1, 2 ou 3 |
| `> ` | <kbd>⇧⌘B</kbd> | Citation |
| Trois accents graves, puis une espace | <kbd>⌥⌘C</kbd> | Bloc de code |
| `---` | | Séparateur |
| | <kbd>⌥⌘0</kbd> | Texte |
| | <kbd>⌘Z</kbd>, <kbd>⇧⌘Z</kbd> | Annuler, rétablir |

Sélectionnez du texte pour afficher le menu contenant **Gras**, **Italique**, **Barré**, **Code en ligne**, **Modifier le lien**, **Transformer en** et **Rechercher dans le transcript**.

Guide : [Mettre en forme pendant la saisie](/moxie/docs/fr/editor/formatting/).

## Menu barre oblique

| Saisie ou touche | Résultat |
| --- | --- |
| `/` en début de ligne ou après une espace | Ouvrir le menu |
| Lettres | Filtrer la liste |
| <kbd>↓</kbd> <kbd>↑</kbd> | Sélectionner un élément |
| <kbd>Enter</kbd> ou <kbd>Tab</kbd> | Insérer l’élément |
| <kbd>Esc</kbd> | Fermer le menu. Le texte saisi reste dans la note. |

Guide : [Menu barre oblique](/moxie/docs/fr/editor/slash-menu/).

## Liens et mentions

| Saisie ou touche | Résultat |
| --- | --- |
| Sélectionner les mots, puis appuyer sur <kbd>⌘K</kbd> | Lier les mots à une adresse web ou à une note |

## Rechercher et remplacer

| Touches | Résultat |
| --- | --- |
| <kbd>⌘F</kbd> dans une note | Ouvrir la barre de recherche avec les mots sélectionnés |
| <kbd>Enter</kbd> ou <kbd>⌘G</kbd> | Résultat suivant |
| <kbd>⇧Enter</kbd> ou <kbd>⇧⌘G</kbd> | Résultat précédent |
| <kbd>Esc</kbd> | Fermer la barre de recherche |
| <kbd>⌘F</kbd> dans le volet de transcription | Accéder au champ **Rechercher dans la transcription** |
| <kbd>Enter</kbd>, <kbd>⇧Enter</kbd> dans le champ **Rechercher dans la transcription** | Occurrence suivante ou précédente |

Guide : [Rechercher et remplacer](/moxie/docs/fr/editor/find-replace/).

## Enregistrement

Quand Moxie enregistre en arrière-plan, une petite commande flotte à l’écran.

| Action | Résultat |
| --- | --- |
| Cliquer sur **Arrêter** dans la commande | Arrêter et enregistrer. Moxie reste en arrière-plan. |
| Cliquer sur le corps de la commande | Ouvrir la note |
| Faire glisser la commande | Déplacer la commande. Moxie mémorise sa position pour chaque écran. |
| **Démarrer maintenant** ou **Ce n'est pas cette réunion** | Répondre à l’invite de réunion détectée |
| **Continuer à enregistrer** | Annuler l’arrêt automatique à la fin d’une réunion |
| **Plus** à côté du bouton **Arrêter** dans le volet de transcription | **Réunion en présentiel**, **Copier l’avis aux participants** |
| **Ouvrir la note** sur la ligne **En cours de réunion.** | Ouvrir la note de l’enregistrement |
| Saisir du texte dans le champ **Poser une question sur cette réunion** | Poser une question pendant l’enregistrement |

La commande reste invisible dans les partages et les captures d’écran.

Guides : [Commande d’enregistrement](/moxie/docs/fr/record/recording-control/), [Démarrer et arrêter un enregistrement](/moxie/docs/fr/record/start-stop/).
