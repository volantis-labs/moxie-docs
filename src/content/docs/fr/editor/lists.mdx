Saisissez un marqueur de liste en début de ligne. Utilisez ensuite le clavier pour modifier la liste.

| Saisie ou touche | Résultat |
| --- | --- |
| `- ` | Liste à puces |
| `1. ` | Liste numérotée |
| `[ ] ` | Liste de tâches |
| `[x] ` | Tâche cochée |
| <kbd>Enter</kbd> | Nouvel élément |
| <kbd>Tab</kbd> | Augmenter le retrait |
| <kbd>⇧Tab</kbd> | Réduire le retrait |
| <kbd>⌘Enter</kbd> | Cocher ou décocher la tâche au point d’insertion |

## Replier une sous-liste

1. Placez le pointeur sur un élément contenant une sous-liste. Un chevron apparaît à côté de l’élément.
2. Cliquez sur le chevron. Moxie masque la sous-liste.
3. Cliquez à nouveau sur le chevron. Moxie affiche la sous-liste.

Moxie ne mémorise pas les listes repliées. Quand vous rouvrez la note, toutes les listes sont dépliées.

## Exemple

Saisissez cette ligne :

```text
- Plan de lancement
```

Appuyez sur <kbd>Enter</kbd>, puis sur <kbd>Tab</kbd>. Saisissez « Réserver la salle ». Cette tâche apparaît en retrait sous « Plan de lancement ».
