Collez du texte dans une note. Moxie met le texte Markdown en forme.

| Contenu collé | Résultat |
| --- | --- |
| Markdown en texte brut, par exemple depuis un éditeur de texte | Texte mis en forme |
| Texte d’une page web | Texte qui conserve le gras, les listes et les autres mises en forme |
| Une adresse web | Un lien |
| Une adresse web sur des mots sélectionnés | Les mots deviennent un lien |
| Tableau Markdown ou tableau d’une page web | Un tableau |
| Une capture d’écran | Une image dans **Mes notes** |
| Texte de Word ou d’Excel | Du texte modifiable et non une image |

## Annuler la mise en forme

1. Collez du texte Markdown.
2. Appuyez une fois sur <kbd>⌘Z</kbd>. La note affiche les caractères Markdown en texte brut.
3. Appuyez à nouveau sur <kbd>⌘Z</kbd>. Moxie supprime le texte collé.

## Coller en texte brut

Utilisez l’une des deux méthodes :

- Appuyez sur <kbd>⇧⌘V</kbd>.
- Faites un clic droit dans la note → **Coller en texte brut**.

Moxie colle les caractères tels quels. Dans un bloc de code, le texte collé reste toujours tel quel.

## Exemple

Copiez ces deux lignes depuis un fichier texte brut et collez-les dans une note :

```text
## Actions
- [ ] Envoyer le **budget**
```

Moxie affiche le titre « Actions » et une tâche à cocher. Le mot « budget » est en gras.
