Les dossiers permettent de regrouper vos notes. La corbeille conserve les notes supprimées pendant 30 jours.

## Classer une note dans un dossier

1. Dans la barre latérale, sous **Dossiers**, cliquez sur **Nouveau dossier** (+).
2. Saisissez un nom et appuyez sur <kbd>Enter</kbd>.
3. Ouvrez une note.
4. En haut de la note, cliquez sur **Aucun dossier**.
5. Sélectionnez le dossier.

Cliquez sur un dossier dans la barre latérale pour voir ses notes. Sa page propose **Renommer** et **Supprimer le dossier**. Pour supprimer le dossier, cliquez sur **Supprimer le dossier**, puis sur **Supprimer dossier pour de bon ?** Moxie conserve les notes.

## Supprimer et restaurer une note

1. Ouvrez la note.
2. Cliquez sur **Placer dans la corbeille**.
3. Pour récupérer la note, cliquez sur **Corbeille** dans la barre latérale, puis sur **Remettre**.

Pour supprimer immédiatement une note, cliquez sur **Supprimer définitivement** dans **Corbeille**, puis sur **Supprimer pour toujours ?** Les fichiers exportés, les sauvegardes de Moxie et les copies Time Machine restent intacts.

Après 30 jours dans **Corbeille**, Moxie supprime définitivement la note. Ce délai est fixe.

## Exemple

Dans **Corbeille**, chaque ligne indique le temps écoulé depuis la suppression :

```text
Supprimé 3 jours il y a
```
