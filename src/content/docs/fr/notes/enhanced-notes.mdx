Après l’enregistrement, Moxie rédige les notes enrichies sur ce Mac à partir de la transcription. Vos propres notes restent dans **Mes notes**.

1. Ouvrez la note.
2. Cliquez sur **Amélioré** pour lire les notes enrichies. Cliquez sur **Mes notes** pour revenir à vos notes.
3. Pour changer de modèle, cliquez sur son nom à côté de **Refaire**, par exemple **Général**.
4. Choisissez un modèle. Moxie rédige à nouveau les notes enrichies.

Cliquez sur **Refaire** pour rédiger à nouveau les notes avec le même modèle.

Si vous avez modifié les notes enrichies, Moxie affiche **Remplacer vos notes modifiées ?** Cliquez sur **Remplacer** ou sur **Garder mes modifications**.

Pour que Moxie utilise aussi vos propres notes, activez l’option **Réglages → Fonctions IA → Les notes enrichies doivent-elles utiliser vos propres notes ?**

## Modèles

| Groupe | Modèles |
| --- | --- |
| **Général** | Général, Bref, Détaillé, Citations clés |
| **Équipe** | Réunion d’équipe, Planification et lancement, Rétrospective, Remue-méninges |
| **Personnes** | Entretien individuel, Entretien d’embauche |
| **Clients** | Entretien client, Entretien utilisateur |

Le groupe **Récents** affiche les 3 derniers modèles utilisés.

## Exemple

Le modèle **Général** produit les sections suivantes :

```text
Résumé
Décisions
Questions ouvertes
Actions et prochaines étapes
```

Les affirmations sont accompagnées de citations. Cliquez sur une citation pour ouvrir la transcription à la ligne correspondante.
