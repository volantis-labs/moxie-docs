Pendant l’enregistrement, le volet de transcription affiche les paroles des participants à mesure qu’ils parlent.

1. Ouvrez la note de l’enregistrement. Le volet de transcription s’ouvre à droite.
2. Lisez les lignes. Chacune indique un horodatage et un intervenant.
3. Pour trouver un mot, saisissez-le dans **Rechercher dans la transcription**.
4. Appuyez sur <kbd>Enter</kbd> pour passer à l’occurrence suivante.

Avant les premiers mots, le volet affiche **À l’écoute…**. La dernière ligne reste visible. Faites défiler vers le haut pour lire les lignes précédentes.

| Touches | Résultat |
| --- | --- |
| <kbd>⇧⌘\\</kbd> | Ouvrir ou fermer le volet de transcription |
| <kbd>⌘F</kbd> avec le curseur dans le volet | Accéder à **Rechercher dans la transcription** |
| <kbd>Enter</kbd> | Résultat suivant |
| <kbd>⇧Enter</kbd> | Résultat précédent |
| <kbd>Esc</kbd> | Effacer la recherche |

## Exemple

```text
00:42  Je      Regardons le plan.
00:47  Autres  Le premier point est le budget.
```

L’étiquette **Je** correspond à votre micro et **Autres** au son de la réunion. Après la réunion, Moxie distingue les intervenants dans les lignes portant l’étiquette **Autres**. La transcription reste dans la note.
