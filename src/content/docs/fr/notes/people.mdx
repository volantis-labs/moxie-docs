Moxie crée une page pour chaque personne qui participe à vos réunions. Elle présente les notes qui mentionnent cette personne et les réunions auxquelles elle participe.

Moxie ajoute les personnes à partir des invités du calendrier, des intervenants identifiés, des noms saisis après `@` et de votre compte de connexion.

## Ouvrir la page d’une personne

| Emplacement | Action |
| --- | --- |
| Une note | Cliquer sur une mention `@` |
| Le volet de transcription | Cliquer sur la ligne des participants, puis sur un nom |
| Recherche (<kbd>⌘K</kbd>) | Saisir un nom ou une adresse e-mail, puis sélectionner la personne sous **Personnes** |

La page est en lecture seule. Elle affiche le nom, l’adresse e-mail si Moxie la connaît, puis les rubriques **Mentions dans les notes** et **Réunions**. Les éléments les plus récents figurent en premier.

1. Cliquez sur une ligne sous **Mentions dans les notes**. Moxie ouvre la note à cette ligne.
2. Cliquez sur une ligne sous **Réunions**. Moxie ouvre la note de cette réunion.

Les notes dans la corbeille ne figurent pas sur cette page.

## Exemple

Une note contient cette ligne :

```text
Décision : @Dana enverra le budget vendredi.
```

Cliquez sur **@Dana**. La page de Dana affiche cette ligne sous **Mentions dans les notes**.
