Une sauvegarde regroupe toutes vos notes dans un fichier `.zep`. Utilisez ce fichier pour les transférer sur un autre Mac.

:::caution
Le fichier n’est pas chiffré. Toute personne qui peut l’ouvrir peut lire vos notes. Si vous l’enregistrez dans un dossier synchronisé, le service en reçoit une copie.
:::

## Sauvegarder les notes

1. Appuyez sur <kbd>⌘,</kbd> pour ouvrir les réglages.
2. Ouvrez **Vos données → Tout sauvegarder**.
3. Cliquez sur **Sauvegarder…**.
4. Choisissez un emplacement et cliquez sur **Enregistrer**.

Vous ne pouvez pas faire de sauvegarde pendant un enregistrement.

| Dans le fichier | Hors du fichier |
| --- | --- |
| Toutes les notes, y compris celles de la corbeille | Votre profil vocal |
| Transcriptions, résumés et détails des réunions | Connexions aux calendriers |
| Dossiers | Modèles téléchargés |
| Réglages de langue, de début de réunion et d’accès des agents | Audio des réunions |
| Mots appris et suggestions bloquées | |

## Restaurer les notes

La restauration remplace les notes, les dossiers et les événements de calendrier de ce Mac. Elle est impossible pendant que Moxie enregistre ou traite une réunion.

1. Ouvrez **Réglages → Vos données → Restaurer une sauvegarde**.
2. Cliquez sur **Restaurer une sauvegarde…**.
3. Sélectionnez le fichier `.zep`.
4. Lisez le message **Remplacer les notes de ce Mac ?**
5. Cliquez sur **Restaurer et redémarrer**.

Moxie redémarre et affiche les notes restaurées. Ce Mac conserve son profil vocal, son choix de micro et son réglage d’ouverture à la connexion.

## Exemple

Le nom du fichier contient la date et l’heure :

```text
Moxie backup 2026-10-06 1530.zep
```
