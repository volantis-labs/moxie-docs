Moxie produit la transcription, les noms des intervenants et les résumés sur votre Mac. Moxie n’envoie pas le contenu de vos réunions à l’extérieur du Mac.

## Ce qui reste sur votre Mac

| Données | Traitement par Moxie |
| --- | --- |
| Audio | Moxie conserve l’audio le temps de traiter la note, puis le supprime. Si une étape échoue, Moxie garde l’audio pour réessayer. |
| Transcriptions, notes, résumés, noms des intervenants et texte à l’écran | Moxie les conserve sur votre Mac. |
| Événements du calendrier | Moxie accède à votre calendrier en lecture seule et enregistre les événements sur votre Mac. |

## Protéger les notes sur le disque

Moxie ne chiffre pas ses fichiers. FileVault, une fonction de macOS, chiffre le disque de votre Mac.

Si FileVault est désactivé, **Réglages → Vos données** affiche **FileVault est désactivé**. Cliquez sur **Vérifiez FileVault** pour ouvrir les réglages FileVault de macOS.

## Quand Moxie utilise le réseau

| Utilisation | Quand |
| --- | --- |
| Téléchargement des modèles | Pendant la configuration et lorsque vous téléchargez à nouveau un modèle |
| Recherche de mises à jour | Tant que Moxie est ouvert |
| Calendrier | Tant qu’un compte Google ou Microsoft est connecté |
| Diagnostics | Si les diagnostics sont activés. Consultez [Diagnostics](/moxie/docs/fr/data/diagnostics/). |
| Formulaire d’adresse e-mail professionnelle | Uniquement si vous envoyez le formulaire **Partager votre e-mail professionnel…** |

Lorsque vous supprimez une note, vos fichiers exportés, vos sauvegardes et vos copies Time Machine sont conservés.

## Exemple

Pour lire la notice complète dans l’app, ouvrez **Réglages → Vos données → Notice sur la confidentialité**.

Consultez la [politique de confidentialité](https://volantislabs.dev/moxie/privacy/) complète.
