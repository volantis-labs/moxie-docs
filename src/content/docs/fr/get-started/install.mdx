Installez Moxie à partir d’un fichier DMG. Téléchargez ensuite les modèles qui produisent la transcription et les résumés sur votre Mac.

## Installer l’app

1. Consultez la page [Configuration requise](/moxie/docs/fr/get-started/requirements/).
2. Téléchargez le fichier DMG depuis [volantislabs.dev/moxie](https://volantislabs.dev/moxie/). Un fichier est prévu pour les Mac à puce Apple et un autre pour les Mac Intel.
3. Ouvrez le fichier DMG.
4. Déplacez Moxie dans le dossier Applications.
5. Ouvrez Moxie depuis le dossier Applications.

## Ouvrir Moxie pour la première fois

1. Sur l’écran **Choisissez votre langue**, sélectionnez une langue.
2. Cliquez sur **Continuer**.
3. [Se connecter et associer son calendrier](/moxie/docs/fr/get-started/sign-in/).
4. Accordez les autorisations indiquées sur la page [Autorisations](/moxie/docs/fr/get-started/permissions/).
5. Dans **Accueil**, repérez **Télécharger les modèles**. La ligne en dessous indique la taille du téléchargement.
6. Cliquez sur **Télécharger**.

Vous ne téléchargez les modèles qu’une fois. Vous pouvez utiliser Moxie pendant le téléchargement. En cas d’interruption, cliquez sur **Reprendre** ou **Réessayer**. Le téléchargement reprend là où il s’est arrêté.

## Exemple

Une fois le téléchargement terminé, **Accueil** affiche ces lignes :

```text
Modèles prêts
La transcription et les résumés fonctionnent maintenant sur ce Mac
```
