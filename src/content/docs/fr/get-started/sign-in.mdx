Avant d’utiliser Moxie, connectez-vous avec votre compte Google ou Microsoft. Cette étape associe aussi votre calendrier.

1. Ouvrez Moxie. Au premier démarrage, l’écran **Se connecter à Moxie** apparaît après le choix de la langue.
2. Cliquez sur **Continuer avec Google** ou sur **Continuer avec Microsoft**.
3. Connectez-vous à votre compte dans le navigateur.
4. Autorisez l’accès à vos calendriers. Moxie a besoin de cet accès pour terminer la connexion.
5. Revenez dans Moxie.

Moxie peut lire votre calendrier, mais ne peut pas le modifier. Il utilise vos événements pour afficher les prochaines réunions, nommer les notes et suggérer des noms d’intervenants. Les événements restent sur votre Mac.

Vous pouvez connecter un seul compte à la fois. Pour changer de compte, déconnectez-vous d’abord.

Votre entreprise peut exiger une autorisation pour un compte professionnel Microsoft 365. Si Moxie affiche **Contactez votre administrateur informatique**, demandez à votre administrateur informatique d’autoriser Moxie. Reconnectez-vous ensuite.

## Exemple

Suivez ce chemin pour consulter votre compte, choisir des calendriers ou vous déconnecter :

**Réglages → Général → Compte de calendrier**

- L’option **Afficher les calendriers** affiche un interrupteur pour chaque calendrier.
- L’option **Se déconnecter** déconnecte votre compte de Moxie.
