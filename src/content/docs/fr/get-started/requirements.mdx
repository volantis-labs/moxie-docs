Pour utiliser Moxie, votre Mac doit répondre aux conditions suivantes.

| Élément | Configuration requise |
| --- | --- |
| macOS | Version 15 ou ultérieure |
| Processeur | Puce Apple ou processeur Intel à 4 cœurs ou plus |
| Mémoire | 16 Go pour toutes les fonctions. Avec moins de 16 Go, Moxie utilise un mode allégé. |
| Compte | Compte Google ou Microsoft |
| Réseau | Pour se connecter, télécharger les modèles, rechercher les mises à jour et accéder au calendrier |

En mode allégé, Moxie utilise moins de mémoire. Pour une longue réunion, il rédige le résumé en plusieurs parties.

Sur un Mac Intel, le traitement après la réunion prend plus de temps. Le résumé d’une réunion de 60 minutes peut prendre environ 15 minutes.

Si la version de macOS ou le processeur ne convient pas, Moxie affiche **Cette Mac ne peut pas exécuter Moxie**. Cliquez sur **Quitter**.

## Vérifier à nouveau le matériel

1. Appuyez sur <kbd>⌘,</kbd> pour ouvrir **Réglages**.
2. Cliquez sur **Aide et informations**.
3. Sous **Quelque chose ne fonctionne pas ?**, repérez **Revérifier le matériel**.
4. Cliquez sur **Vérifier**.

## Exemple

En haut de la rubrique **Aide et informations**, vous trouverez la version, le type de processeur et le résultat :

```text
Moxie 0.1.0 · Apple silicon · Conforme aux exigences.
```
