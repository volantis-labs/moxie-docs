Repérez le message affiché par Moxie et suivez l’instruction correspondante.

## Pendant un enregistrement

La commande d’enregistrement affiche les messages suivants.

| Message | Marche à suivre |
| --- | --- |
| **Votre microphone est silencieux** | Si vous avez coupé le micro dans l’app de réunion, vous n’avez rien à faire. Sinon, cliquez sur **Choisir le micro**. |
| **Aucun son de la réunion** | Cliquez sur **Vérifier la sortie**. Vérifiez que le son de la réunion passe par la sortie sélectionnée. |
| **Périphérique remplacé par** suivi du nom d’un appareil | Cliquez sur **OK**. L’enregistrement continue. |
| **Disque presque plein** | Cliquez sur **Libérer de l'espace**. Supprimez les fichiers dont vous n’avez plus besoin. |
| **Accès au micro retiré** | Cliquez sur **Ouvrir Réglages**. Activez Moxie. |
| **Permission audio système désactivée** | Cliquez sur **Ouvrir Réglages Système**. Activez Moxie. |

## Avant ou après un enregistrement

| Message | Marche à suivre |
| --- | --- |
| **Téléchargement interrompu** | Cliquez sur **Réessayer**. Vérifiez que votre Mac est connecté au réseau et qu’il reste de l’espace sur le disque. |
| **Moxie a besoin d’accéder au calendrier** | Reconnectez-vous. Autorisez l’accès à vos calendriers. |
| **Contactez votre administrateur informatique** | Demandez à votre administrateur informatique d’autoriser Moxie. Reconnectez-vous ensuite. |
| **Connexion expirée.** | Ouvrez **Réglages → Général → Compte de calendrier**. Cliquez sur **Se reconnecter**. |

S’il manque une autorisation, ouvrez **Réglages → Enregistrement** et cliquez sur **Autoriser**.

## Exemple

Vous connectez un casque pendant une réunion. La commande d’enregistrement affiche cette ligne :

```text
Périphérique remplacé par AirPods Pro    OK
```
