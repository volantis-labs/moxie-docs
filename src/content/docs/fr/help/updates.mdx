Moxie détecte et télécharge les nouvelles versions automatiquement. Vous lancez l’installation d’un clic.

1. Laissez Moxie ouvert. Moxie recherche une nouvelle version à chaque démarrage, une fois par heure et après chaque enregistrement.
2. Attendez que Moxie télécharge la nouvelle version. Aucun message ne s’affiche pendant le téléchargement.
3. Repérez le message **Moxie est prêt à être mis à jour** en haut de la fenêtre de Moxie.
4. Cliquez sur **Redémarrer pour mettre à jour**. Moxie redémarre et installe la nouvelle version.

Moxie suspend les téléchargements et les installations de mises à jour pendant un enregistrement. Si un enregistrement commence, le téléchargement s’arrête. Il reprend ensuite. Le message apparaît uniquement en dehors des enregistrements.

Moxie installe la mise à jour lorsque vous cliquez sur **Redémarrer pour mettre à jour**. Les mises à jour proviennent des versions publiées par Moxie sur GitHub.

## Exemple

Voici le message :

```text
Moxie est prêt à être mis à jour
Redémarrez Moxie entre les réunions pour installer la mise à jour.    Redémarrer pour mettre à jour
```

Pour vérifier votre version, ouvrez **Réglages → Aide et informations**. Elle figure en haut de la page :

```text
Moxie 0.1.0 · Apple silicon · Conforme aux exigences.
```
