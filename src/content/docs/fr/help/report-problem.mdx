Signalez un problème depuis Moxie. Moxie fournit les données techniques. Vous décrivez ce qui s’est passé.

1. Appuyez sur <kbd>⌘,</kbd> pour ouvrir **Réglages**.
2. Cliquez sur **Aide et informations**.
3. Sous **Quelque chose ne fonctionne pas ?**, repérez **Signaler un problème**.
4. Cliquez sur **Signaler…**. Votre navigateur ouvre un nouveau ticket sur GitHub.
5. Décrivez ce qui s’est passé.
6. Relisez le texte en entier. Envoyez ensuite le ticket.

Moxie ajoute sa version, des informations sur votre Mac et les derniers codes d’erreur. Ces données ne contiennent aucun contenu de réunion.

Le ticket est public. Vous devez avoir un compte GitHub. N’y collez aucun extrait de transcription, titre de note, nom de personne, nom de dossier ou chemin de fichier.

Si vous préférez éviter un ticket public, écrivez à [hello@getmoxieapp.com](mailto:hello@getmoxieapp.com).

## Créer un dossier d’assistance

Le dossier d’assistance est un fichier ZIP contenant les journaux locaux et un profil de votre Mac. Moxie ne l’envoie pas.

1. Dans **Aide et informations**, cliquez sur **Afficher les détails du dossier de diagnostic**.
2. Cliquez sur **Examinez le fichier de support**.
3. Lisez le contenu.
4. Cliquez sur **Enregistrer le ZIP enregistré**.
5. Joignez le fichier à votre signalement.

## Exemple

Le ticket commence par des lignes comme celles-ci :

```text
Moxie 0.1.0 sur macOS 15.1.0, M2 (arm64), 8 cœurs, 16 GiB RAM.
Codes d'erreur récents : Aucun enregistrement.
```
