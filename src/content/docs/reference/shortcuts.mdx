This page lists each shortcut and trick. Each group has a link to its full page.

## Moxie window

| Press | Result |
| --- | --- |
| <kbd>⌘K</kbd> | Open search |
| <kbd>⌘F</kbd> | Open search, when the caret is not in a note or in the transcript pane |
| <kbd>↓</kbd> <kbd>↑</kbd>, <kbd>Enter</kbd>, <kbd>Esc</kbd> | In search: select a result, open it, close search |
| <kbd>⌘\\</kbd> | Hide or show the sidebar |
| <kbd>⇧⌘\\</kbd> | Show or hide the transcript pane of a note |
| <kbd>⌘S</kbd> | Save the note immediately |
| <kbd>⌘,</kbd> | Open **Settings** |
| <kbd>Enter</kbd> | In a chat field: send the question |

Full pages: [Search](/moxie/docs/find/search/), [Chat](/moxie/docs/find/chat/), [Settings](/moxie/docs/reference/settings/).

## Format text

| Type | Or press | Result |
| --- | --- | --- |
| `**bold**` | <kbd>⌘B</kbd> | Bold |
| `*italic*` | <kbd>⌘I</kbd> | Italic |
| `~~strike~~` | <kbd>⇧⌘S</kbd> | Strikethrough |
| `` `code` `` | <kbd>⌘E</kbd> | Inline code |
| `# `, `## `, `### ` | <kbd>⌥⌘1</kbd>, <kbd>⌥⌘2</kbd>, <kbd>⌥⌘3</kbd> | Heading 1, 2, 3 |
| `> ` | <kbd>⇧⌘B</kbd> | Quote |
| Three backticks, then a space | <kbd>⌥⌘C</kbd> | Code block |
| `---` | | Divider |
| | <kbd>⌥⌘0</kbd> | Text |
| | <kbd>⌘Z</kbd>, <kbd>⇧⌘Z</kbd> | Undo, redo |

Select text to show a menu with **Bold**, **Italic**, **Strikethrough**, **Inline code**, **Edit link**, **Turn into** and **Find in transcript**.

Full page: [Format as you type](/moxie/docs/editor/formatting/).

## Slash menu

| Type or press | Result |
| --- | --- |
| `/` at the start of a line or after a space | Open the menu |
| Letters | Filter the list |
| <kbd>↓</kbd> <kbd>↑</kbd> | Select an item |
| <kbd>Enter</kbd> or <kbd>Tab</kbd> | Add the item |
| <kbd>Esc</kbd> | Close the menu. The typed text stays. |

Full page: [Slash menu](/moxie/docs/editor/slash-menu/).

## Links and mentions

| Type or press | Result |
| --- | --- |
| Select words, then <kbd>⌘K</kbd> | Link the words to a web address or to a note |
| <kbd>⌘K</kbd> with the caret in a link | **Open link**, **Remove link** |
| Select words, then paste a web address | The words become a link |
| Click a link | Open the web address or the note |
| `@` | Mention a person |
| Click a mention | Open the page of the person |

Full pages: [Links](/moxie/docs/editor/links/), [Mention people](/moxie/docs/editor/mentions/).

## Find and replace

| Press | Result |
| --- | --- |
| <kbd>⌘F</kbd> in a note | Open the find bar with the selected words |
| <kbd>Enter</kbd> or <kbd>⌘G</kbd> | Next match |
| <kbd>⇧Enter</kbd> or <kbd>⇧⌘G</kbd> | Previous match |
| <kbd>Esc</kbd> | Close the find bar |
| <kbd>⌘F</kbd> in the transcript pane | Go to the **Search transcript** field |
| <kbd>Enter</kbd>, <kbd>⇧Enter</kbd> in **Search transcript** | Next, previous match |

Full page: [Find and replace](/moxie/docs/editor/find-replace/).

## Tables and images

| Type or press | Result |
| --- | --- |
| `\| Item \| Price \|`, then <kbd>Enter</kbd> | Make a table |
| <kbd>Tab</kbd>, <kbd>⇧Tab</kbd> | Next, previous cell. <kbd>Tab</kbd> in the last cell adds a row. |
| <kbd>Enter</kbd> in a table | The cell below |
| Click **⋯** in a cell | Add or delete rows and columns |
| `/image` | Select an image file |

| Click an image | Edit its description |

Full pages: [Tables](/moxie/docs/editor/tables/), [Images](/moxie/docs/editor/images/).

## Recording

When Moxie records and its window is not in front, a small control floats on the screen.

| Action | Result |
| --- | --- |
| Click **Stop** on the control | Stop and save. Moxie does not come to the front. |
| Click the body of the control | Open the note |
| Drag the control | Move it. Moxie keeps the position for each display. |
| **Start now** or **Not this meeting** | Answer the prompt for a detected meeting |
| **Keep recording** | Cancel the automatic stop at the end of a meeting |
| **More** beside **Stop** in the transcript pane | **In person meeting**, **Copy participant notice** |
| **Open note** in the **Meeting in progress** line | Open the note of the recording |
| Type in the **Ask about this meeting** field | Ask a question during the recording |

The control does not show in a shared screen or in a screenshot.

Full pages: [Recording control](/moxie/docs/record/recording-control/), [Start and stop](/moxie/docs/record/start-stop/).
