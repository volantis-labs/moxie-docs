After a meeting, Moxie divides the transcript into speakers. You give each speaker a name. In an in-person meeting, Moxie uses your voice profile to label your voice **Me**.

## Name a speaker

1. Open the transcript pane of the note.
2. Click a speaker label, for example **Speaker 2**.
3. Type a name. The list shows the names that match.
4. Click a row in the list. The last row uses the name that you typed.

Moxie changes all lines of this speaker in this note. The list gives the source of each name:

| Source | Meaning |
| --- | --- |
| **From calendar** | A person in the calendar event |
| **From the meeting app** | A name that the meeting app shows |
| **In this meeting** | A different speaker of this note |
| **People** | A person that Moxie knows |

If the **Me** label is on the voice of a different person, click **Not me**.

## Record your voice profile

1. Open **Settings → General**.
2. Below **Should Moxie recognise your voice?**, click **● Record**.
3. Read the line on the card aloud.
4. Do steps 2 and 3 for each of the 3 cards.

If **● Record** is not available, click **Download** first.

## Example

After the third card, Moxie shows this line:

```text
Good to go. Transcripts now mark you as "Me".
```
