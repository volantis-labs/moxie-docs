---
title: Updates
description: How Moxie gets a new version and how you install it.
---

Moxie finds and downloads a new version automatically. You start the installation with one click.

1. Keep Moxie open. Moxie looks for a new version at each start, one time each hour and after each recording.
2. Wait while Moxie downloads the new version. You see nothing during the download.
3. Find the message **Moxie is ready to update** at the top of the Moxie window.
4. Click **Restart to update**. Moxie restarts and installs the new version.

Moxie does not download or install an update during a recording. If a recording starts, Moxie stops the download. The download starts again after the recording. The message shows only when no recording is in progress.

Moxie installs an update only after you click **Restart to update**. Moxie gets its updates from its releases on GitHub.

## Example

The message looks like this:

```text
Moxie is ready to update
Restart between meetings to install the update.    Restart to update
```

To see your version, go to **Settings → Help & about**. The top of the page shows the version:

```text
Moxie 0.1.0 · Apple silicon · Meets requirements.
```
