---
title: Report a problem
description: Send a problem report from Moxie and make a support bundle.
---

Report a problem from Moxie. Moxie writes the technical data, and you write what occurred.

1. Press <kbd>⌘,</kbd> to open **Settings**.
2. Click **Help & about**.
3. Below **Something not working?**, find **Report an issue**.
4. Click **Report…**. Your browser opens a new GitHub issue.
5. Write what occurred.
6. Read the full text. Then submit the issue.

Moxie adds your Moxie version, data about your Mac and the recent error codes. It adds no meeting content.

The issue is public, and you need a GitHub account. Do not paste transcript text, note titles, names, folder names or file paths.

If you do not want a public issue, send an email to [hello@getmoxieapp.com](mailto:hello@getmoxieapp.com).

## Make a support bundle

A support bundle is a ZIP file that contains the local logs and a profile of your Mac. Moxie does not upload it.

1. In **Help & about**, click **Show support bundle details**.
2. Click **Review support bundle**.
3. Read the contents.
4. Click **Save reviewed ZIP**.
5. Attach the file to your report.

## Example

The issue starts with lines such as these:

```text
Moxie 0.1.0 on macOS 15.1.0, M2 (arm64), 8 cores, 16 GiB RAM.
Recent error codes: none recorded.
```
